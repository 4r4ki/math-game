# math-game

**かけ算ラン！なかま増やしゲーム**

最初は1人。毎ラウンド出てくる2つの計算問題（ゲート）から1つを制限時間内に選ぶと、
**今の人数 × 答え** だけなかまが増えます。全10ラウンドで最終的な人数が多いほど高評価！

## 遊び方

`index.html` をブラウザで開くだけ（ビルド不要・依存なし）。

- クリック／タップ、または `←` `→`（`A` `D` / `1` `2`）キーでゲートを選択
- 制限時間を過ぎると答えが小さい方のゲートへ強制的に進みます
- 後半は式が複雑になり、答えが `1/2` などの **1より小さいワナ** も出現
- **問題のレベル**と**スピード**を別々に選べます
  - かんたん：四則計算（小学生レベル）
  - ふつう：ルート・分数・累乗・負の数・一次方程式（中学レベル）
  - むずかしい：極限（lim）・微分・積分・log・三角関数・場合の数・Σ・複素数（高校レベル）
  - スピード：ゆっくり（×1.5）／ふつう／はやい（×0.6）。ラウンドが進むほど制限時間が短くなります
- 結果画面では「理論上の最大人数」との達成率・コンボ・各ラウンドの履歴を表示
- 自己ベストは「レベル × スピード」の組み合わせごとにブラウザに保存されます
